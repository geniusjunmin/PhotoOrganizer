## 简体中文商品页草稿

**名称**　照片整理工具（以商店名称预留结果为准）

**简短说明**　预览后批量归档和改名，让照片按时间与设备有序保存。

**详细说明**

将手机、相机和旧硬盘中的照片整理到普通文件夹。先检查日期来源与目标文件名，再确认执行。

- 按年、月复制归档，保留原件，也可在原文件夹批量改名。
- 支持 JPG、JPEG、PNG，按拍摄时间、设备或原名组织文件。
- 可选择复制 MP4、MOV，视频按文件修改时间归档。
- 预览中逐项勾选，检查日期回退、重名编号、重复内容和无法处理的项目。
- 批量任务提供阶段进度、当前文件、取消与预计剩余时间。
- 操作历史提供撤销预览。复制副本撤回到归档目录的专属文件夹，原地改名可恢复旧名。
- 程序中断后核对未完成记录，文件身份及内容匹配时继续完成，冲突项目保留待核对。
- 支持简体中文、英文，亮色、暗色及跟随系统主题。
- 所有整理与校验均在本机进行。

**系统要求**　Windows 11 x64，最低系统构建 26100。本地 NTFS 归档目标，存储卡需作为有盘符的来源读取。

**格式边界**　HEIC、RAW 和其他未支持格式在预览中跳过。原地改名会跳过常见照片伴随文件组。EXIF 缺失时会明确使用文件修改时间，MP4/MOV 也使用文件修改时间。

**分类建议**　照片与视频

**搜索词草稿**　照片整理，照片归档，批量改名，拍摄时间，EXIF，离线相册

## English listing draft

**Name**　Photo Organizer, subject to name reservation

**Short description**　Preview, archive and rename photos by date and device.

**Description**

Organize photos from phones, cameras and old drives into regular Windows folders. Review date sources and destinations before confirming changes.

- Copy into year/month folders while preserving originals, or rename files in place.
- Organize JPG, JPEG and PNG photos by date and device or keep their original names.
- Optionally copy MP4 and MOV videos using filesystem modified dates.
- Review fallback dates, numbered name collisions, duplicate content and skipped formats.
- Follow batch progress, the current file and estimated time remaining, with cancellation support.
- Preview undo from operation history. Copies move into a dedicated withdrawal folder, and renamed files return to their original names.
- Verify unfinished tasks after interruption. Matching file identity and content allow recovery, while conflicting items remain for review.
- Switch between Simplified Chinese and English, with light, dark and system themes.
- Organization and verification run locally on your PC.

**Requirements**　Windows 11 x64, build 26100 or later. A local NTFS archive destination. Removable sources must have a drive letter.

**Formats**　HEIC, RAW and other unsupported formats are skipped. In-place renaming skips common companion groups. Missing EXIF and opt-in MP4/MOV use filesystem modified dates.

## 审核说明

应用使用 runFullTrust，以当前用户身份读取所选照片目录并执行复制或同目录改名。所有写入均需要预览和明确确认。未知格式不会参与写入，目标创建禁止覆盖，已编辑或被替换文件会阻止自动撤销。程序不请求管理员运行级别，不安装驱动或后台服务。

“定位所选文件”使用 Process.Start 启动 Windows 目录内的 explorer.exe，并将所选文件的完整路径作为独立参数传递。程序不把照片作为可执行程序启动。WACK 可选 API 扫描同时标记此调用及自包含 .NET/WinForms 框架中的相关引用，提交时应说明用途。

审核者可使用项目的自动生成样本。选择来源与一个独立空 NTFS 归档目录，扫描并核对时间来源，复制后查看历史，选择行并预览撤销。撤回副本会位于归档目录的 .photo-organizer-withdrawn 内。原地改名使用所选来源，在历史中可恢复旧名。

商品页截图必须来自最终应用。建议中文、英文各准备四张，分别展示预览、日期来源与冲突、执行进度、历史撤销。素材尺寸与最终表单以提交时要求为准。[商品页素材](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/add-and-edit-store-listing-info)

## 正式包构建

运行 scripts/Prepare-Toolchain.ps1、scripts/Build.ps1、scripts/Test.ps1。取得后台身份后，调用 scripts/Package.ps1，提供以下参数。

| 参数 | 填写值 |
| --- | --- |
| PackageName | 后台 Package/Identity/Name |
| Publisher | 后台 Publisher，完整复制大小写与标点 |
| DisplayName | 已预留的应用显示名称 |
| PublisherDisplayName | 实际发布者显示名称 |
| Version | 递增的四段版本，例如 1.0.0.0，末段为 0 |

将隐私政策补齐发布主体和联系方式并公开托管，再填写后台 URL。提交前在目标市场机器验证商店安装与升级，并重新运行本地认证。软件包、真实身份、描述和截图应对应同一版本。[认证流程](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msix/app-certification-process)
