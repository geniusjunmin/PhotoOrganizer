# 照片整理工具隐私政策

2026-10-31 · 发布前审阅稿

发布主体、支持邮箱与公开托管地址将在发布者账号注册后填入。本稿用于本地审阅和应用内说明，正式商店提交需使用补齐联系信息的公开版本。

## 本地处理

本应用在用户选择的文件夹中读取照片、文件名、时间和设备元数据，规划文件名并在确认后执行复制或改名。应用内没有账号系统、广告、遥测或照片上传服务。照片处理、哈希校验和历史操作在本机完成。

## 设置和操作记录

应用保存语言、主题和 SQLite 操作历史。历史包含原路径、目标路径、操作时间、文件身份、校验哈希、批次和操作状态，用于恢复与撤销。开发运行版默认保存在当前用户本地应用数据目录 PhotoOrganizer 中。MSIX 安装版保存在该包的 LocalState/PhotoOrganizer 中。

复制暂存文件位于归档目录的 .photo-organizer-staging。撤销复制时，仍匹配的副本移至归档目录 .photo-organizer-withdrawn 中。遇到身份或内容变化、路径占用或恢复依据不足时，文件会保留待核对。

## 用户操作

用户可选择扫描范围、取消勾选项目、中止任务、预览撤销、核对恢复、导出历史或清空历史。清空历史会移除对应的自动撤销依据。已完成的用户文件、归档和撤回文件保留。

完整历史导出包含路径，只有用户选择导出位置并确认后才写入指定 JSON 文件。诊断导出包含应用和运行时版本、操作系统构建、语言、主题、包身份及历史条目数量，排除照片内容、照片元数据详情、绝对路径和用户身份标识。应用不会自动向第三方发送这些文件。

## 卸载与保留

用户照片和外部归档目录由用户管理。MSIX 包数据由 Windows 管理，卸载前应导出需要保留的历史。停止恢复会保留原件、副本和暂存文件，供用户核对。

## 第三方软件

应用随附 MetadataExtractor、XmpCore、Microsoft.Data.Sqlite、SQLitePCLRaw 和 .NET 运行时相关声明。第三方许可证可在应用「帮助与隐私」内查阅。

## 联系与更新

正式发布主体与支持邮箱待发布者确认。功能或数据处理方式变更时同步更新隐私政策及日期，并在应用与商店资料提供更新后的入口。
